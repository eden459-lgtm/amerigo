# AmeriGo — הגרסה להעלאה לאינטרנט

התיקייה הזו מוכנה להעלאה כמו שהיא. **אין צורך בשום התקנה או בנייה** בצד השני.

## מה יש כאן

| קובץ | למה הוא נחוץ |
|---|---|
| `index.html` | כל האפליקציה — הקוד, העיצוב ו-109 המקומות בתוך קובץ אחד |
| `manifest.webmanifest` | מאפשר להתקין את האפליקציה במסך הבית |
| `icon-192.png` / `icon-512.png` | האייקון שמופיע במסך הבית ובלשונית |

## העלאה ל-GitHub Pages

1. פותחים ריפו חדש ב-GitHub.
2. גוררים לתוכו את **ארבעת הקבצים** שבתיקייה הזו (לא את התיקייה עצמה — את הקבצים).
3. בריפו: **Settings → Pages**, ותחת *Branch* בוחרים `main` ואז `/ (root)` → **Save**.
4. אחרי דקה-שתיים מתקבל קישור בסגנון `https://<שם-המשתמש>.github.io/<שם-הריפו>/` — זה הקישור לשיתוף.

> חשוב: הקובץ חייב להישאר בשם `index.html`, אחרת הקישור לא ייפתח לבד.

## התקנה במסך הבית (למי שמקבל את הקישור)

- **אייפון:** פותחים את הקישור בספארי → כפתור השיתוף → "הוסף למסך הבית"
- **אנדרואיד:** פותחים ב-Chrome → תפריט שלוש הנקודות → "התקנת אפליקציה"

התוצאה: אייקון על המסך, פתיחה במסך מלא בלי סרגלי דפדפן — בדיוק כמו אפליקציה רגילה.

## מה שכדאי לדעת

- **לכל אחד יש טיול משלו.** הנתונים נשמרים בדפדפן של כל משתמש בנפרד. שיתוף הקישור משתף את *האפליקציה*, לא את המסלול שלך.
- מי שרוצה לראות את המסלול המלא לניו יורק ואורלנדו — בוחר באשף הפתיחה **"מסלול לדוגמה"**.
- **המפה** בתוך האפליקציה היא OpenStreetMap (בחינם, בלי מפתח API). כפתורי הניווט פותחים את Google Maps ו-Uber האמיתיים.
- **מזג האוויר** נטען מ-Open-Meteo (בחינם, בלי מפתח). אם אין אינטרנט הוא פשוט לא מוצג.

## עדכון הגרסה באינטרנט

אחרי שינוי בקוד, מריצים בתיקיית הפרויקט:

```bash
npm run web
```

ומעלים מחדש את הקבצים מהתיקייה הזו.
