# AmeriGo — הגרסה להעלאה לאינטרנט

התיקייה הזו מוכנה להעלאה כמו שהיא. **אין צורך בשום התקנה או בנייה** בצד השני.

## מה יש כאן

| קובץ | למה הוא נחוץ |
|---|---|
| `index.html` | כל האפליקציה — הקוד, העיצוב ו-109 המקומות בתוך קובץ אחד |
| `manifest.webmanifest` | מאפשר להתקין את האפליקציה במסך הבית |
| `icon-192.png` / `icon-512.png` | האייקון שמופיע במסך הבית ובלשונית |

## העלאה ל-GitHub Pages

1. פותחים ריפו חדש ב-GitHub.
2. גוררים לתוכו את **הקבצים** שבתיקייה הזו (לא את התיקייה עצמה).
3. בריפו: **Settings → Pages**, ותחת *Branch* בוחרים `main` ואז `/ (root)` → **Save**.
4. אחרי דקה-שתיים מתקבל קישור בסגנון `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

> חשוב: הקובץ חייב להישאר בשם `index.html`.

## התקנה במסך הבית

- **אייפון:** פותחים את הקישור בספארי → כפתור השיתוף → "הוסף למסך הבית"
- **אנדרואיד:** פותחים ב-Chrome → תפריט שלוש הנקודות → "התקנת אפליקציה"

## איך זה עובד מבחינת נתונים

- **לכל אחד יש טיול משלו.** הנתונים נשמרים בדפדפן של כל משתמש בנפרד (localStorage), על המכשיר שלו בלבד.
- שיתוף הקישור משתף את **האפליקציה**, לא את המסלול שלך.
- כל מי שנכנס מקבל אשף פתיחה ובונה טיול משלו מאפס.
- מי שרוצה להתחיל מחדש: **פרופיל → "התחלת טיול חדש משלי"**.
- מסלול הדוגמה (ניו יורק ואורלנדו) הוא אופציונלי — רק מי שבוחר בו במפורש מקבל אותו.

## מה חינמי כאן

- **המפה** — OpenStreetMap, בלי מפתח API. כפתורי הניווט פותחים את Google Maps ו-Uber האמיתיים.
- **מזג האוויר** — Open-Meteo, בלי מפתח. אם אין אינטרנט הוא פשוט לא מוצג.

## עדכון הגרסה באינטרנט

אחרי שינוי בקוד, מריצים בתיקיית הפרויקט:

```bash
npm run web
```

ומעלים מחדש את הקבצים מהתיקייה הזו.
